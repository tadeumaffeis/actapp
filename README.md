"# actapp" 

# Para instalar o actapp no Sistema Operaciona Windows

1) Execute o application.bat
   - Aguarde o término da instalação.
   - Uma janela de Login aparecerá
   - Forneça o endereço de e-mail informado pelo professor e pressione <ENTER>
   - Em seguida, digite a senha de acesso e clique no botão [<Login>]

# Para instalar o actapp no Sistema Operacional Linux

1) Abra o terminal e navegue até a pasta onde está o actapp

2) Navegue até a pasta bin [ACTAPPDIR/bin]
   - posicionado na pasta do actapp, digite: 
     $ cd ./bin

3) Execute o comando:
     $ chmod 755 application.sh

4) Em seguida, execute a instalação do actapp
     $ sh ./application.sh

5) Caso a instalação ocorra com sucesso, aparecerá a janela de Login.
